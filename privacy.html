Memolight Privacy Policy

Last updated: July 1, 2026

한국어

개요

Memolight는 지원 사이트와 사용자가 직접 허용한 도메인에서 개인 메모, 라벨, 색상 표시를 로컬로 관리하기 위한 브라우저 확장 프로그램입니다. 이 확장은 사용자의 메모 데이터를 개발자 서버 또는 제3자 서버로 전송하지 않습니다.

저장되는 데이터

Memolight는 기능 제공을 위해 다음 데이터를 사용자의 브라우저 로컬 저장소에 저장할 수 있습니다.

  • 회원 닉네임, 사이트에서 감지한 회원 식별자, 또는 사용자가 직접 저장한 문구
  • 사용자가 직접 작성한 메모와 짧은 라벨
  • 사용자가 선택한 표시 색상
  • 메모 작성일, 수정일, 마지막 확인 시각
  • 직접 추가한 도메인, 선택자 범위, 사이트별 켜기/끄기 설정 등 확장 프로그램 설정

데이터 사용 방식

저장된 데이터는 닉네임 또는 문구 옆 메모 표시, 메모 편집, 관리 페이지 검색, 사이트별 표시 설정, CSV 내보내기, 암호화 백업 내보내기 및 가져오기 기능을 제공하는 데 사용됩니다. Memolight는 광고, 추적, 분석, 판매 목적으로 사용자 데이터를 사용하지 않습니다.

외부 전송 및 공유

Memolight는 저장된 메모, 라벨, 닉네임, 회원 식별자, 문구 메모, 직접 추가한 도메인 설정을 외부 서버로 전송하거나 제3자와 공유하지 않습니다. 확장 프로그램은 패키지에 포함된 코드만 실행하며, 외부 서버에서 실행 가능한 코드를 다운로드하거나 실행하지 않습니다. 사용자가 후원 링크를 누르면 외부 서비스인 Ko-fi 페이지가 열리며, 후원 결제 정보는 Memolight가 처리하거나 저장하지 않습니다.

Chrome Web Store Limited Use

Memolight의 사용자 데이터 사용은 확장 프로그램의 단일 목적과 사용자-facing 기능을 제공하거나 개선하는 데만 한정됩니다. 사용자 데이터는 광고, 추적, 판매, 신용평가, 데이터 중개, 또는 관련 없는 목적으로 사용되거나 전송되지 않습니다. 개발자는 사용자의 로컬 메모 내용을 읽거나 수집하지 않습니다.

내보내기와 백업

사용자가 직접 CSV 파일을 내보내는 경우 CSV 파일은 암호화되지 않습니다. 암호화 백업 파일은 사용자가 입력한 비밀번호를 기반으로 AES-GCM 방식으로 암호화됩니다. 내보낸 파일의 보관과 공유는 사용자 책임입니다.

데이터 삭제

사용자는 Memolight 관리 페이지에서 개별 메모를 삭제하거나 로컬 데이터를 초기화할 수 있습니다. 브라우저에서 확장 프로그램을 제거하거나 브라우저 프로필 데이터를 삭제하는 경우 로컬에 저장된 데이터도 삭제될 수 있습니다.

문의

이 개인정보처리방침에 대한 문의는 프로젝트 저장소의 이슈 또는 배포자가 제공한 연락 수단을 통해 보낼 수 있습니다.

English

Overview

Memolight is a browser extension for keeping local notes, labels, and color markers on supported sites and user-allowed domains. The extension does not transmit the user's memo data to the developer's server or to third-party servers.

Data Stored

Memolight may store the following data in the user's browser local storage to provide its features.

  • Member nicknames, member identifiers detected on supported sites, or text phrases saved by the user
  • Notes and short labels written by the user
  • Marker colors selected by the user
  • Created, updated, and last-seen timestamps
  • Extension settings such as directly added domains, selector scopes, and per-site enable or disable states

How Data Is Used

Stored data is used to show memo markers next to nicknames or saved text phrases, edit notes, search the management page, control per-site display settings, export CSV files, and export or import encrypted backups. Memolight does not use user data for advertising, tracking, analytics, or sale.

Transmission and Sharing

Memolight does not transmit stored notes, labels, nicknames, member identifiers, text memos, or directly added domain settings to external servers, and does not share them with third parties. The extension runs only code included in the extension package and does not download or execute remote executable code. If the user opens the support link, an external Ko-fi page is opened. Memolight does not process or store donation payment information.

Chrome Web Store Limited Use

Memolight's use of user data is limited to providing or improving the extension's single purpose and user-facing features. User data is not used or transferred for advertising, tracking, sale, creditworthiness, data brokerage, or unrelated purposes. The developer does not read or collect the user's local memo contents.

Export and Backup

CSV files exported by the user are not encrypted. Encrypted backup files are encrypted with AES-GCM using a password entered by the user. The user is responsible for storing and sharing exported files safely.

Data Deletion

Users can delete individual notes or reset local data from the Memolight management page. Removing the extension or deleting browser profile data may also delete locally stored data.

Contact

Questions about this privacy policy can be sent through the project repository issues or the contact method provided by the publisher.
