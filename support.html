Memolight Support

Support page for the Memolight browser extension.

About Memolight

Memolight is a browser extension for adding private notes, labels, and color markers to authors on supported community sites and user-allowed domains. Notes are stored locally in the browser extension storage. Optional Google Drive sync encrypts notes on the device before sending them directly to the user's hidden Google Drive app-data folder. Connected memo changes are synchronized automatically, and Sync now remains available.

Getting Started

  • Install Memolight from the Chrome Web Store or Firefox Add-ons, or from the App Store or TestFlight when available.
  • Enable the Memolight extension in your browser settings.
  • Allow site access for the supported sites where you want memo markers to appear.
  • Open a supported page, select a marker next to an author, and add a private note.

Markers and Page Display

By default, filled dots mark saved memos and outline dots let you add a new memo. Enable Show saved memos only to hide empty dots without hiding saved memos. The Page Alert Badge can show memo and match counts in the bottom-right corner and can be turned off independently.

Custom Domains and Page Diagnosis

From the management page, you can add a custom domain, grant access only to that domain, save selected page text from the browser context menu, and optionally limit matching to a CSS selector. Click the Memolight toolbar icon on a page to diagnose access, enablement, selector matches, detected targets, and marker counts without including memo content or the full page URL in the report.

Source links saved with new memos remove common OAuth/OIDC callback credentials and state/error parameters, tracking values, and request signatures while preserving supported-site navigation codes and fragments required to reopen supported pages.

History, Backup, and Sync

Memolight keeps the latest 20 versions per memo for active and recoverably deleted records and lets you review or restore earlier versions. It does not silently prune history using a separate global total. Deleted memos remain recoverable until you permanently remove them. The management page can export a readable, unencrypted CSV or export and import a password-protected AES-GCM backup; backup changes and projected storage usage are shown before confirmation. Backup passwords accept a minimum of four characters, while eight or more characters is recommended.

Google Drive sync is separate and optional. Local data remains available when sync is disconnected or temporarily fails. Disconnecting does not delete local or remote data, while Delete Drive data removes the remote Memolight vault without deleting local memos.

If 1.4.4 confirms that the exact encrypted snapshot recorded for this installation is damaged, automatic sync pauses and the management page offers an explicit repair action. After confirmation, Memolight requires the account-verified sync key, creates and fully verifies a noncanonical staging copy, promotes it, and only then renames the damaged file as a retained vault-scoped quarantine copy instead of deleting it. Failures before promotion leave the damaged canonical file unchanged. If a result becomes ambiguous after a verified promotion, Memolight keeps the verified replacement, preserves the warning, and lets a later explicit repair safely reuse or adopt it. Delete Drive data also removes current-vault recovery staging and quarantine copies when the user explicitly deletes the vault.

Starting in 1.4.5, remote deletion verifies the Drive listing after snapshots and recovery objects are removed and again after the key envelope is removed. If an object cannot be identified or Drive still lists an attempted file, Memolight reports failure and preserves local sync state for a safe retry instead of showing a false success.

Memo Limits and Live Management Updates

Editor saves that create a memo or change its body can contain up to 10,000 characters. Import, synchronization, sanitization, and history restoration preserve longer legacy data, and the editor can retain it unchanged instead of truncating it during upgrade.

An open management page refreshes when another tab changes local memo data. Memo-editor and custom-site memo drafts are preserved; entered backup/recovery passwords and a selected import file defer refresh until cleared. A stale editor save is rejected without overwriting or resurrecting the external version, and its draft remains available to copy. Repeated page observations persist a memo's last-seen time at most once every six hours; an observation-only update does not advance the sync mutation journal or schedule an extra sync mutation, although a later database snapshot can include that timestamp.

In 1.4.5 and later, an encrypted-backup confirmation is valid only for the exact local database used to calculate its preview. If another tab changes a memo, history, deletion record, or setting first, the preview is discarded and must be reviewed again.

Private Memo UI in 1.4.4 and Later

Starting with 1.4.4, memo text, short labels, source context, history, and unsaved drafts are displayed in an isolated extension-origin UI instead of the website DOM. A site can still observe marker existence and color and, if the Page Alert Badge is enabled, its memo and match counts. It cannot read the private memo fields through ordinary page scripts.

The desktop memo window uses a fixed outer size and scrolls long content inside it. If the isolated frame cannot open, including in private/incognito extension contexts where 1.4.4 intentionally does not use the on-page private UI, Memolight fails closed: hover preview stays hidden and an explicit view, edit, or summary action opens the management page instead of placing private content into the website page. Versions earlier than 1.4.4 do not use this isolation boundary.

Version 1.4.5 also invalidates every temporary private-UI session for a tab when its top-level document begins reloading or navigating. This prevents an earlier document's token from surviving a page load even on browser versions that do not expose a document ID to extensions.

Supported Sites

Memolight currently supports Reddit, X, Threads, Hacker News, Hatena Bookmark, Bluesky, Slickdeals, Mobile01, DVDPrime, MLBPARK, Bobaedream, and Inven. Support can vary when a site changes its layout or blocks extension access.

DVDPrime Activity Alerts

In Memolight 1.4.x on Chrome, Edge, and Firefox, DVDPrime users can optionally monitor comments, recommendations, and subscription posts through the browser's existing signed-in session. Open the supported sites section, expand DVDPrime, grant DVDPrime access, and enable activity alerts. The available intervals are 5, 15, 30, and 60 minutes, with 15 minutes as the default. Each activity type can be included or excluded from notifications and the toolbar badge.

Chrome, Edge, and Firefox can delay extension alarms while the browser or device is inactive. Chrome/Edge 1.4.3 and Firefox 1.4.6 restore a missing schedule and perform one overdue check when the extension background resumes, but they cannot wake a fully closed browser, Firefox suspended by Android power management, or a sleeping device. The DVDPrime panel shows the last automatic alarm and delayed-check recovery attempt for troubleshooting.

Firefox may separately request optional data consent for DVDPrime activity and Google Drive synchronization. Google Drive actions may also request exact optional Google service access, plus the validated localhost callback on Android; these sites are not required at installation. Declining them leaves local memo and backup features available. Firefox notifications have a View action but no Chrome-style View all activity button; open the full list from the DVDPrime panel. DVDPrime activity alerts are unavailable in Safari.

Firefox upgrades from older Memolight versions may retain Google service access that those versions required at installation. Version 1.4.4 checks this once and removes only orphaned exact Google API or localhost grants. It preserves unrelated site access and stored data. When both optional Google Drive data categories are granted, any already-granted origins used by the current platform are kept; the next explicit Drive action requests anything missing.

Troubleshooting

  • If markers do not appear, confirm that the extension is enabled and that Memolight has access to that site in the browser's extension settings.
  • If the browser asks for permission on a site, choose Allow only for the sites where you want to use Memolight.
  • If a page was already open before enabling the extension, refresh the page.
  • If a site layout has changed, send the site URL and a short description of the problem.
  • If automatic or manual sync fails, local memos remain available. Check the Google authorization and network connection, then try Sync now again.
  • If the management page reports that this device's Drive snapshot is damaged, review the repair explanation and select Verify and repair only when you are ready to confirm a remote change. The action does not delete the damaged file; it keeps a quarantine copy after verifying the replacement.
  • If Firefox reports that Google Drive permission is missing, choose Connect, Reconnect, or Sync now and approve the optional Google service and data-consent request. Automatic sync does not open this prompt and remains paused after denial or revocation.
  • If DVDPrime reports that no login session is available, sign in to DVDPrime in the same browser profile, confirm DVDPrime access in Memolight, and use Check now.
  • If DVDPrime activity counts update but no system notification appears, confirm the browser's optional notification permission and the operating system's notification settings. The toolbar badge remains available as a fallback.
  • If Chrome alerts arrive only after the browser becomes active, confirm that at least one Chrome window remains running and review the last automatic alarm and recovery attempt in the DVDPrime panel. A fully closed browser or sleeping device cannot be woken by an extension alarm.
  • If Firefox Android alerts arrive only after reopening Firefox, allow unrestricted battery use for Firefox if appropriate for your device and review the last alarm and recovery attempt in the DVDPrime panel. Android can still defer a sleeping Firefox process, so immediate screen-off delivery is not guaranteed.

Privacy

Memolight does not collect memo contents or send them to a developer server. Optional Google Drive sync sends only device-encrypted data directly to the user's Drive app-data folder. See the Memolight Privacy Policy for details.
